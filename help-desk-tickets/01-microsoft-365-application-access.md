# Ticket 01 — Microsoft 365 Application Access

## Ticket Information

- **Requester:** Emily Brown
- **Department:** Finance
- **Category:** Microsoft 365
- **Priority:** Medium
- **Assigned Technician:** Stefon Kreller
- **Status:** Resolved
- **Date Resolved:** August 19, 2026

## Issue

The user reported being unable to access a required Microsoft 365 application.

## Troubleshooting

1. Reviewed the user's Microsoft 365 account.
2. Checked the user's license assignment.
3. Identified an issue with Microsoft 365 application access.
4. Verified the appropriate Microsoft 365 license assignment.
5. Confirmed that application access was restored.

## Resolution

Verified the user's Microsoft 365 license assignment and restored application 
access. The user confirmed successful sign-in.

## Automation Demonstrated

The ticket was managed through the SharePoint-based IT Support Requests system.

After the ticket status was changed to **Resolved**, the Power Automate 
ticket-status workflow triggered automatically and sent the requester a 
resolution notification containing:

- Ticket title
- Resolved status
- Assigned technician
- Resolution notes
- Date completed
