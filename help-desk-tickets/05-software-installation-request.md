# Ticket 05 — Software Installation Request

## Ticket Information

- **Requester:** Amanda Taylor
- **Department:** Sales
- **Category:** Software
- **Priority:** Medium
- **Status:** New
- **Assigned Technician:** Stefon Kreller

## Issue

The user requested installation of an approved business application on their 
workstation.

The software was required to complete normal daily job responsibilities.

## Ticket Submission

The support request was created using the published **IT Support Request 
Manager** Power Apps application.

The following information was entered:

- Requester
- Department
- Category
- Priority
- Status
- Assigned Technician
- Description

Resolution Notes and Date Resolved were intentionally left blank because the 
ticket had not yet been resolved.

## Power Apps Testing

The ticket was used to verify that the Power Apps application could successfully 
create a new support request.

Testing confirmed that:

1. The New Ticket form could be opened.
2. User and ticket information could be entered.
3. SharePoint Person fields displayed readable user names.
4. Choice fields could be selected.
5. The support request could be saved.
6. The new ticket appeared in the support-ticket system after submission.

## Result

The Software Installation Request was successfully created through Power Apps 
and stored in the SharePoint IT Support Requests data source.

This demonstrated that the Power Apps interface could be used as a functional 
front end for ticket creation instead of requiring technicians to work directly 
inside the SharePoint list.
